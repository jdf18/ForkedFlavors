# ForkedFlavors
ForkedFlavors is an open-source recipe-sharing platform where users can **discover, share, and fork recipes** to create their own variations, easy to explore and personalize recipes.

## Features
- **Browse & Search Recipes** – Find new dishes from around the world.  
- **Fork & Customize** – Modify any recipe and save it as your own.  
- **Upload & Share** – Share your own creations with the community.  
- **Open Source** – Contribute and improve the platform!

## Tech Stack

- Frontend: Bootstrap, JavaScript, AJAX
- Backend: Node.js, Express
- Database: JSON
- Authentication: Session tokens (not secure)
- Testing: JEST


## Testing

Unit tests can be run by using `npm test`

A test instance of the server can be started using `npm run start_test`

This has the following set up:
- User account test, password test
- User account test2, password test2
- Multiple recipes, account bios, etc.

## Getting Started

### **1. Clone the Repository**
```sh
git clone https://github.com/jdf18/ForkedFlavors.git
cd ForkedFlavors
```

### **2. Install dependencies **
```sh
npm install
```

### **3. Run the server **
```sh
npm start
```

This starts the server at `http://localhost:8080`.
